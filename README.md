# 🏎️ Apex 3D Speed Simulator

A real-time 3D browser racing game with realistic physics, custom car paints, and serverless peer-to-peer multiplayer powered by Three.js and WebGL.

🎮 **[Click Here to Play the Game Live](https://swatiabhiaarav-dot.github.io/car-game/)**

---

## ✨ Features

* **Multiple Car Classes**: Choose between GT Sport, V8 Muscle, and Hypercar models.
* **Custom Garage**: Live color pickers for body clearcoat paint and wheel rims.
* **Realistic Driving Dynamics**: Acceleration, braking, handbrake drifting, wheel rotation, and chassis suspension lean.
* **Serverless Multiplayer**: Connect directly with friends using WebRTC (PeerJS) without needing an external backend server.
* **Dual Control Support**: Works on PC (Keyboard) and Mobile/Tablet (On-Screen Touch Controls).
* **Zero Asset Setup**: Built entirely with procedural code — runs instantly on GitHub Pages.

---

## 🕹️ Controls

### Keyboard (PC / Mac)
* **Drive / Accelerate**: `W` or `Up Arrow (↑)`
* **Brake / Reverse**: `S` or `Down Arrow (↓)`
* **Steer Left**: `A` or `Left Arrow (←)`
* **Steer Right**: `D` or `Right Arrow (→)`
* **Drift / Handbrake**: `Space`
* **Reset Car**: Click the **Reset Car** button on screen

### Touch (Mobile / Tablet)
* **Steering**: Left (`◀`) and Right (`▶`) buttons
* **Throttle / Brake**: Up (`▲`) to drive, Down (`▼`) to brake/reverse

## 🌐 How to Play with Friends (Multiplayer)

1. Open the game link on both devices:  
   👉 `https://swatiabhiaarav-dot.github.io/car-game/`
2. **Player 1 (Host)**: Click the **Copy My Room ID** button.
3. Send this copied ID to **Player 2** (via WhatsApp, chat, etc.).
4. **Player 2**: Paste the Room ID into the text box and click **Connect to Friend**.
5. Both cars will appear on the track together in real time!
